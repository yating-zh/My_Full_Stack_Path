-----  Nodemon
1. what is Nodemon: is a utility monitors for any changes in your source and automatically restart your server.
2. Installisation
  > npm install -g nodemon
  > npm install -g nodemon --save-dev
3. Edit package.json
  "scripts": {
    "dev": "nodemon server.js"
  }
4. Run
  >npm run dev
